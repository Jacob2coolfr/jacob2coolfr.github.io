Privacy Policy

Last updated: October 24, 2026

This policy explains how Purffle Uploader (“the app”), operated by The Timelore Project, handles information when it is connected to a Google account.

Information the app accesses

When the owner signs in with Google, the app requests permission to manage videos on the owner’s YouTube channel (the YouTube Data API “upload” and related scopes). It uses this permission only to upload and schedule videos that the owner created with the app.

How information is stored

The sign-in token is stored only on the owner’s own computer, in the app’s folder. It is not sent to any server operated by The Timelore Project, and it is not shared with anyone.

How information is used

The app does not read, collect, sell or share personal data from YouTube or any other Google service. It does not use Google user data for advertising, and it does not transfer it to third parties.

Google API Services User Data Policy

The app’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from the Google Account permissions page at myaccount.google.com/permissions, and by deleting the token file from the app’s folder.
