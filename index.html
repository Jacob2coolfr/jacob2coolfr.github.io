Purffle Uploader

A private publishing tool run by The Timelore Project.

Purffle Uploader is a personal automation tool. It creates short educational videos and uploads them, as scheduled private videos, to YouTube channels owned and operated by The Timelore Project.

What it does

  • Writes short fact-based scripts and turns them into vertical videos.
  • Uploads those videos to the owner’s own YouTube channels using the YouTube Data API.
  • Schedules each upload to go public at a set time.

Who it is for

Only the owner of The Timelore Project and its channels. It is not offered to the public, and it does not access anyone else’s YouTube account.
